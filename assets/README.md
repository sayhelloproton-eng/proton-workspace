# Assets

`assets/` 保存 workspace 长期拥有的静态资源真源，例如架构图、截图、SVG、演示图片和知识库插图。

原则：

- 源文件留在本地 workspace，不把飞书 media token、Block ID 或远端 URL 反写成本地真源。
- `assets/知识库/` 用于公开知识库文章引用的静态资源；主题路径可随真实知识结构自然增长。
- 项目运行时资产仍由对应项目仓库拥有，不因为被知识库引用就搬入这里。
- 临时截图、测试输出和一次性中间产物不进入本目录。

飞书发布时，发布流程负责解析本地图片、完成上传/导入并把最终正文覆盖到远端；本地 Markdown 与静态资源继续是内容真源。
