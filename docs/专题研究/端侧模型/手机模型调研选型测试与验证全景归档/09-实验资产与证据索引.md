## 10. 证据解释优先级

当旧脚本 summary 和后续人工/合同复核冲突时，按以下顺序解释：

```text
真实 API / File / Runtime / Git result
> 对应时间点的 frozen schema + raw structured output
> 专项回归
> 大型综合 benchmark summary
> 测试脚本自己的 ALL_GREEN 标志
> Chat 中未经证据支持的猜测
```

任何旧文件名里的 `final` / `freeze` 都不能单独证明它仍是当前基线。原始资产已经退休时，本归档只能证明“当时已形成并审计过该结论”；需要今天的产品事实时必须重新读取当前 Owner。
