## 当前关键取舍

- `proflow-rag` 是 headless RAG Capability Service；`chatweb` 是独立 consumer/product。
- QueryExecution 先 pin Active Snapshot，再执行全部 lexical/vector/chunk read；后台 activation 不能让单次 query 混版本。
- Published Contract DTO 自己拥有类型，不导出 Knowledge Aggregate 或 persistence identity。
- Vector Derived Windows 在检索层归并回 Source Chunk；最终 Citation 仍指向 Source Chunk 的 immutable SourceCoordinate。

后续真实实现若推翻某项决策，继续记录“原判断 → 新证据 → 新决策”，不覆盖历史。
