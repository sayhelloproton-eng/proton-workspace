# 阶段实战记录模板

每个阶段都尽量保留下面这些信息，但不为了模板完整而制造不存在的内容。

## 1. 阶段目标
这一步真正要证明什么？为什么现在做，而不是以后做？

## 2. 开始前的认知与假设
当时认为问题是什么、准备怎样解决、有哪些还没有被验证的判断。

## 3. 设计与取舍
采用什么方案；有哪些替代方案；为什么暂时不选它们；关联哪些 SDD/DDD/ADR。

## 4. 实际实现过程
关键步骤、模块 ownership、核心数据流和重要代码入口。重点解释“为什么这样实现”，不复制代码。

## 5. 遇到的问题
记录真实现象、错误信息、触发条件，以及第一反应是否正确。

## 6. 排查与根因
怎样缩小范围、用了什么证据、排除了什么假设，最后如何确认 root cause。

## 7. 修复与设计变化
具体修复；是否暴露原 Spec/目录/抽象有问题；如果改设计，为什么值得付出迁移成本。

## 8. 验证与数据
测试、Smoke、Eval、Benchmark、延迟、召回率、失败切片等真实结果。

## 9. 阶段结论
最终学到了什么；哪些判断被证实、被推翻或仍待验证。

## 10. 面试提炼
30 秒版本、3 分钟版本、可能追问、可展示证据和对应 Git commit。
