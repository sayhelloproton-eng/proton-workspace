# 06 怎么把 AI 变成长期能力

核心问题：怎么把一次成功或失败的 AI 使用，沉淀成个人、团队和组织可以重复获得、持续改进而且默认安全的能力。

现在按四层能力成熟过程阅读：

1. [01_怎么把一次成功变成可复用的AI资产.md](01_怎么把一次成功变成可复用的AI资产.md) —— 从 Case / Template / CLI / Skill / Workflow / Agent 到 Shared Service，判断什么值得沉淀，以及一项资产为什么必须有 Contract、Owner、Version 和 Eval。
2. [02_团队怎么建立公共AI能力而不是重复造轮子.md](02_团队怎么建立公共AI能力而不是重复造轮子.md) —— 从真实重复里长出 Model / Knowledge / Tool / Eval / Observability / Registry / Golden Path 等公共能力，而不是先造一个大而全的 AI 中台。
3. [03_安全与治理怎么成为长期能力的一部分.md](03_安全与治理怎么成为长期能力的一部分.md) —— 把原 06 的完整安全主线并入长期能力：Permission / Identity / Sensitive Data / Prompt Injection / Tool & Supply Chain / Blast Radius / Audit / Security Eval / Risk Tier 都变成可复用的平台边界。
4. [04_组织怎么形成持续变强的AI能力飞轮.md](04_组织怎么形成持续变强的AI能力飞轮.md) —— 把 Production Failure、Security Incident、Regression、Asset、Platform、Review、协作方式和 Capability Map 连成组织持续变强的闭环。

最终目标不是让组织拥有更多 Prompt、更多 Agent 或更大的 AI 平台，而是让每一次真实工作都能留下可验证、可复用、可治理的东西，让下一次从更高的起点开始。
